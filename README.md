# อ่าน Model Card ให้เป็น: กรณีศึกษา Gemini 4 Argon

สไลด์ประกอบการบรรยาย 10 นาที (21 หน้า) สำหรับเภสัชกร
อ่าน model card ของ Gemini 4 Argon ผ่าน 4 คำถามแบบเดียวกับการอ่านเอกสารกำกับยา

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages ของ repo นี้
เลื่อนหน้าด้วยลูกศรซ้าย/ขวา ปุ่มด้านล่าง หรือปัดหน้าจอ

ผู้จัดทำ: ดร.ภก.วิรุณ เวชศิริ · คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์
